# LevelUp LVP

Premium luxury vinyl plank installation site for Greenville, SC and a 50-mile radius.

Built with TanStack Start, React 19, Tailwind CSS v4, and Vite.

## Local

```bash
npm install
npm run dev
```

## Deploy

Vercel auto-detects the Vite / TanStack Start app. Production build:

```bash
npm run build
```

Leads from the quote form are stored in the browser for the ops desk at `/admin`. Wire Resend or a database when you are ready for real inbox delivery.
